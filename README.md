五元力定义 (The Five Forces)

| 符号 | 名称 | 含义 |
|---|---|---|
| f₁ | 安全 (Security) | 对生存、稳定、可控的基本需求 |
| f₂ | 价值 (Value) | 被认可、被需要、有意义的感受 |
| f₃ | 情绪 (Emotion) | 情感体验与情绪调节能力 |
| f₄ | 认知 (Cognition) | 理解、判断、决策的思维过程 |
| f₅ | 创造 (Creation) | 表达、生成、改变现状的冲动 |

精神势能场E=w1f1+w2f2+w3f3+w4f4+w5f5
