五元理论：从第一性原理推导意识与生命的构成

Five-Element Theory: Deriving the Constitution of Life and Consciousness from First Principles

这是“五元理论”的核心开源版，包含从第一性原理出发的完整公理基础、五元力定义、总公式与势能层级推导。

五元力定义 (The Five Forces)

| 符号 | 名称 | 含义 |
|---|---|---|
| f₁ | 安全 (Security) | 对生存、稳定、可控的基本需求 |
| f₂ | 价值 (Value) | 被认可、被需要、有意义的感受 |
| f₃ | 情绪 (Emotion) | 情感体验与情绪调节能力 |
| f₄ | 认知 (Cognition) | 理解、判断、决策的思维过程 |
| f₅ | 创造 (Creation) | 表达、生成、改变现状的冲动 |

核心公式

精神势能场 E = w₁f₁ + w₂f₂ + w₃f₃ + w₄f₄ + w₅f₅
其中各权重满足 wᵢ ≥ 0，且 Σwᵢ = 1。
